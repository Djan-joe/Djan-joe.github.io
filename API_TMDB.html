Application de gestion de films

Projet académique - React / Spring Boot

Présentation du projet

Ce projet consiste à développer une application web permettant de rechercher des films grâce à l'API TMDB (The Movie Database) et de gérer une liste personnalisée de films.

L'application repose sur une architecture séparant le frontend, le backend et la base de données.

Architecture de l'application

  • Frontend : React pour l'interface utilisateur.
  • Backend : Spring Boot et Java pour la logique applicative.
  • Base de données : PostgreSQL pour le stockage des données.
  • API externe : TMDB pour récupérer les informations relatives aux films.

Fonctionnalités

  • Recherche et consultation de films.
  • Récupération de données depuis l'API TMDB.
  • Gestion d'une liste personnalisée de films.
  • Communication entre frontend et backend via une API REST.
  • Gestion des utilisateurs et authentification.
  • Stockage des données dans PostgreSQL.

Technologies et outils utilisés

  • React
  • Java / Spring Boot
  • PostgreSQL
  • Docker / Docker Compose
  • GitLab CI/CD
  • OpenAPI
  • Bruno

Environnement et déploiement

Ce projet m'a permis de découvrir plusieurs outils utilisés dans les environnements professionnels :

  • Conteneurisation des services avec Docker.
  • Configuration d'une base PostgreSQL conteneurisée.
  • Automatisation de tâches avec GitLab CI/CD.
  • Documentation des endpoints avec OpenAPI.
  • Tests des requêtes HTTP avec Bruno.

Compétences développées

Ce projet m'a permis de mieux comprendre l'architecture d'une application web moderne, la communication entre plusieurs services, l'utilisation d'une API externe et la gestion d'une base de données.
