Gestion d'une bibliothèque

Projet académique - PHP / MariaDB

Présentation du projet

Ce projet consiste à développer une application web permettant de gérer une bibliothèque, ses utilisateurs et les informations associées aux ouvrages.

L'objectif est de mettre en pratique les connaissances acquises en développement backend, en programmation PHP et en gestion de bases de données relationnelles.

Fonctionnalités développées

  • Gestion des utilisateurs.
  • Authentification et gestion des connexions.
  • Consultation et modification des informations.
  • Interactions avec une base de données MariaDB.
  • Sécurisation des données utilisateurs.

Sécurisation des données

Une attention particulière a été portée à la protection des données stockées dans la base de données.

  • Hachage : protection de certaines informations à l'aide de fonctions de hachage.
  • HMAC : vérification de l'intégrité et de l'authenticité de certaines données.
  • PDO : utilisation de requêtes préparées pour limiter les risques d'injection SQL.

Technologies utilisées

  • PHP
  • MariaDB / SQL
  • HTML / CSS
  • PDO
  • Apache

Compétences développées

Ce projet m'a permis de renforcer mes compétences en programmation PHP, en gestion de bases de données relationnelles et en sécurisation des données. J'ai également approfondi mes connaissances concernant l'authentification et l'organisation du code.
